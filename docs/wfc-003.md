## Use

Select **Planning** from the existing Scheduled Works, Work Packages or Daily Works panel in Operations. Five table views provide Rolling Lookahead, Constraints / Make-Ready, Weekly Commitments, Daily Allocation, and Progress / Plan Reliability. The original 21 panels/eight destinations remain in place, including Overview, All Panels and Original board. Source links use existing navigation; activity and daily entry actions open the original Add/Edit forms.

- **Lookahead:** choose 2–6 weeks (default 3), date anchor, project, week, work area, supervisor, activity status and make-ready. Current, upcoming, delayed, completed and undated records remain distinguishable. Editor planning includes retired records for historical reporting; Site/Client views retain their existing display/retirement filters.
- **Scheduled Works:** enable the optional planning section. Record the existing Workface ID, scope/location/chainage, supervisor/crew, plant requirements, quantities/units, programme source/baseline and evidence references. Working dates remain the original date-range fields. Recorded baseline values stay frozen; previously unrecorded baseline values can be supplied with a change reason. Working-date, quantity and unit revisions require a reason and retain before/after history.
- **Constraints:** create one project-scoped record linked to several activities/workfaces. Record action, owner/organisation, identified/need-by dates, priority, source and evidence. Reported resolution stays blocking until explicitly Closed / verified with confirmation, verifier/date, resolution date and evidence. Cancellation needs a recorded explanation. Status/verification history stays on the original record.
- **Weekly commitments:** select an activity, record committed scope/quantity/crew, criteria, week and completion date. A non-ready/unassessed commitment requires explicit acknowledgement and remains a planning decision. Original snapshot and readiness are frozen. Explicit working-plan amendments and outcome history are separate; they do not rebaseline PPC. Assessed commitments cannot be changed to Unassessed to remove them from the denominator.
- **Daily allocation:** allocate an activity/commitment through the existing Daily Works form. Record work date, incremental quantity for that entry, crew/plant references, actual dates, interruptions and evidence links. Commitment allocations use their explicitly amended working plan. Potential resource overlap is flagged only for matching recorded resource references and overlapping dates; assignments do not confirm availability.

## Calculations and boundaries

Dates are ISO project dates using the existing Australia/Brisbane today rule. Calendar duration is inclusive. Horizon end is anchor + 7 × weeks − 1; activities overlapping the interval include carry-in work. Finish variance is current finish minus recorded baseline finish in calendar days. Delayed means the recorded planned finish has passed without recorded completion; no critical-path/EOT/contractual conclusion is inferred.

Make-ready is derived, never stored as an editable flag. Known outstanding conditions produce **NOT READY**; insufficient assessment without known blockers produces **NOT ASSESSED**; otherwise **READY**. It uses original materials/prerequisite/completion rules and WFC-001 approval/coverage/condition/check rules, plus the activity's planned dates and chainage. Approval effective/expiry bounds are checked against the activity period. Current Workface gates remain conservative; future effective approvals do not become current GO automatically. Legacy materials-only GO is not a fully assessed workface. Free-text Work Package notes remain advisory; structured constraints/checks carry blocking decisions. Derived blockers reference their source, recalculate, and never create duplicate constraint records. Hidden source names, IDs, notes and counts are withheld from audience-facing displays.

Activity actual quantity sums non-cancelled, same-project Daily Works allocation increments in the matching unit. No incompatible units are aggregated. Remaining = max(planned − actual, 0); physical progress = min(actual / planned × 100, 100) only when planned > 0 and actuals are reported. Excess is shown separately. Actual start uses recorded activity/daily dates; activity finish needs its explicit activity field. Hidden actual-source entries cause aggregate actuals to be withheld in that audience view. Quantities do not change Work Package completion, QA acceptance or weekly outcomes automatically.

PPC = achieved / assessed commitments × 100 for the selected project/week, using the original frozen criteria, quantity and completion date. Partial and missed are failures, unassessed are counted separately, unplanned activity is excluded, and an empty assessed denominator is N/A. Achieved requires explicit original-criteria confirmation, recorded evidence, on-time completion and original quantity where recorded. Reason codes are classifications, not liability findings. Audience reports identify that their figures cover permitted displayed commitments.
